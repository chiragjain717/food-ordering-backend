# Food Ordering Backend System

A backend REST API project for an online food ordering system developed using Spring Boot.

## Features
- User Registration & Login
- Restaurant and Menu Management
- Add to Cart Functionality
- Order Placement System
- RESTful APIs
- Database Integration using H2
- Exception Handling
- Layered Architecture

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Maven

## Project Structure
- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer

## Tools Used
- IntelliJ IDEA / VS Code
- Postman
- Git & GitHub

## Future Improvements
- JWT Authentication
- Payment Gateway Integration
- MySQL Integration
- Admin Dashboard
